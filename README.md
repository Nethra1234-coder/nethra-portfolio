## About

AI Engineer, Aug–Oct 2026). It covers my background, projects, current research, skills, and
achievements, with a downloadable résumé.

The hero section features an animated reliability diagram — a nod to the confidence
calibration research I work on, where a model's predicted confidence is checked against its
actual accuracy.

## Built with

## Run locally

No build step required — just open the file:

\`\`\`bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>
open index.html   # macOS
# or just double-click index.html
\`\`\`

## Deploy

Currently deployed with **GitHub Pages**:

1. Repo → **Settings → Pages**
2. Source: \`main\` branch, \`/ (root)\` folder
3. Site publishes at \`https://<your-username>.github.io/<repo-name>/\`

## Updating

- Edit \`index.html\` for content changes (projects, achievements, contact info).
- Edit \`style.css\` to adjust colors, spacing, or type.
- Replace \`resume.pdf\` whenever the résumé changes — the "Résumé" button always points to
  this file, so no link updates needed.
